Boston Tourism Sentiment Analysis

Developed a Python-based web crawling pipeline using Selenium WebDriver to collect Tripadvisor customer review data from dynamic HTML webpages

Automated multi-page scraping workflows by generating paginated review URLs and extracting raw HTML webpage source content

Implemented Regular Expression (Regex) parsing logic to extract reviewer names, ratings, contribution counts, user locations, review messages, review month, and review year from unstructured HTML elements

Built structured SQLite relational databases to store extracted review datasets through automated SQL insertion workflows

Performed data preprocessing, missing value handling, and dataset transformation using Pandas and NumPy for downstream analytics

Applied TextBlob sentiment analysis to evaluate customer review polarity and tourism satisfaction trends from textual review content

Conducted exploratory data analysis (EDA) using statistical summaries, frequency distributions, grouping analysis, and reviewer behavior analytics

Built analytical visualizations using Matplotlib and Seaborn including histogram distributions, scatterplots, contribution frequency analysis, sentiment trend visualization, and reviewer location analysis

Generated word cloud visualizations to identify dominant customer experience themes and recurring tourism feedback patterns from review text data

Result: transformed unstructured Tripadvisor HTML review content into a structured analytical dataset that revealed strong positive customer sentiment, reviewer engagement behavior, and tourism experience trends for the Boston Hop-On Hop-Off Trolley Tour
